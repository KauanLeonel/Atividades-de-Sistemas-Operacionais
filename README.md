# Atividades de Sistemas Operacionais

Bem-vindo ao repositório **Atividades de Sistemas Operacionais**!  
Este repositório contém arquivos e exercícios desenvolvidos ao longo das aulas da disciplina de **Sistemas Operacionais**, como parte das atividades práticas ou listas de exercícios da faculdade, incluíndo um curso de fundamentos em Python.

## 🧠 Sobre

Este projeto agrupa scripts, exemplos e pequenos programas em **Python** relacionados às atividades realizadas durante o semestre. O objetivo principal é organizar, registrar e compartilhar as soluções de cada atividade desenvolvida na matéria.
